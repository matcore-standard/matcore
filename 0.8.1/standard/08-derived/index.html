    2.8 Derived Property (DP) Metadata

    Version 0.8.1

    The metadata for derived properties (MatCore-DP) is tabulated below. A derived property is a property obtained from the results of other computations, e.g. a Raman spectrum computed from phonon modes and dielectric tensors obtained by DFT. (Note: This standard inherits the metadata in the minimal MatCore standard, adding the properties below.)

    The properties are given in settings blocks, each naming the computations it describes. Usually the derived properties of a dataset come from one computation in minimal computation whose method is DP (method-class Post-processing). It names the computations whose results it uses in input, with the role Source data, e.g. the DFT computation that gave the forces and dielectric tensors, or Interaction model for energies and forces it requests as it proceeds. Its block here gives one derived-property entry for each property, with the procedure that obtained it and its parameters in procedure and calculation-parameter, e.g. the finite-difference displacement of the atoms. A property obtained within a computation of another method, e.g. phonons computed by density functional perturbation theory in a DFT computation, is given in a block naming that computation. A result that its computation already names needs no derived entry: a transition path and its energy barrier, e.g. a point defect's migration barrier, found by the nudged elastic band (ps algorithm NEB, minimal task Transition path), are described by that PS computation. A property obtained from such results, e.g. a rate from barriers and attempt frequencies, is a derived entry.

    Examples of derived properties include:

    • Electronic (band structure, density of states (DOS), projected DOS, dielectric function, charge and bonding analysis, etc.)
    • Electron-phonon interactions (superconducting properties, line widths, etc.)
    • Magnetic (magnetics, magnetization, magnons, etc.)
    • Mechanical (elastic constants, stress-strain response, tensile, yield and fracture strengths, hardness, etc.)
    • Microscopy, electron (S/TEM, 4D-STEM, SAED, etc.)
    • Microscopy, scanning probe (STM, AFM, etc.)
    • NMR (chemical shifts)
    • Optical (electronic excitation spectra, low-loss EELS, etc.)
    • Scattering (X-ray and neutron diffraction, reflectivity, pair-distribution function, etc.)
    • Spectroscopy, core-level (XAS, XES, core-loss EELS, XPS, etc.)
    • Spectroscopy, vibrational (Raman, Infrared spectroscopy, etc.)
    • Thermodynamic (free energies, heat capacity, formation energies, melting temperature, etc.)
    • Transport (electronic and thermal conductivity, diffusion, viscosity, defect mobilities, etc.)
    • Vibrational (phonon modes, dispersion, interatomic force constants, vibrational DOS, etc.)

    * required appears at most once repeatable

    settings*

    Settings shared by the computations named in it.

    Required Repeatable
    yes yes
    computation-label*

    The label of a computation these settings apply to.

    Required Repeatable Type Extent Kind Rec. unit
    yes yes string [] inapplicable —
    derived-property*

    Details of a quantity related to material behavior computed based on a computational materials science (CMS) calculation covered by the MatCore standard.

    Required Repeatable
    yes yes

    Note: Give one entry for each property.

    type*

    The kind of property computed.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: Electronic, Electron-phonon interactions, Magnetic, Mechanical, Microscopy, electron, Microscopy, scanning probe, NMR, Optical, Scattering, Spectroscopy, core-level, Spectroscopy, vibrational, Thermodynamic, Transport, Vibrational. Other values are allowed.

    Clarifications:

    • "Electronic" – The electronic structure and quantities obtained from it, e.g. a band structure, a density of states, a dielectric function, or a charge and bonding analysis
    • "Electron-phonon interactions" – The coupling of electrons and lattice vibrations, e.g. superconducting properties or phonon linewidths
    • "Magnetic" – Magnetic order and its excitations, e.g. a magnetization, exchange constants or magnons
    • "Mechanical" – The response to a mechanical load, e.g. elastic constants, a stress-strain response, a tensile, yield or fracture strength, or a hardness
    • "Microscopy, electron" – A simulated electron microscopy image or diffraction pattern, e.g. S/TEM, 4D-STEM or SAED
    • "Microscopy, scanning probe" – A simulated scanning probe image, e.g. STM or AFM
    • "NMR" – Nuclear magnetic resonance parameters, e.g. chemical shifts
    • "Optical" – The response to light through electronic excitations, e.g. an absorption spectrum or low-loss EELS
    • "Scattering" – The scattering of X-rays or neutrons by the structure, e.g. a diffraction pattern, reflectivity or a pair-distribution function
    • "Spectroscopy, core-level" – Spectra from excitations of core electrons, e.g. XAS, XES, core-loss EELS or XPS
    • "Spectroscopy, vibrational" – A simulated vibrational spectrum for comparison with a measurement, e.g. a Raman or infrared spectrum
    • "Thermodynamic" – Thermodynamic quantities, e.g. free energies, heat capacities, formation energies or a melting temperature
    • "Transport" – The transport of charge, heat, mass or momentum, or the motion of defects under a driving force, e.g. an electrical or thermal conductivity, a diffusion coefficient, a viscosity, or the mobility of a dislocation or a grain boundary
    • "Vibrational" – The vibrations of the atoms themselves, e.g. phonon modes and dispersion, interatomic force constants or a vibrational density of states
    name*

    The specific property computed.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Examples: Raman spectrum, Phonon dispersion.

    description*

    Explanation of the derived property.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    procedure*

    How the property was obtained from the results of the computations named in minimal computation › input.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Note: Explain the role of each calculation-parameter entry. The parameters of the calculations the procedure requests from other computations, e.g. the finite-difference displacement of the atoms, are given here, not in the descriptions of those computations.

    calculation-parameter

    A parameter of the procedure that obtained the derived property.

    Required Repeatable
    no yes

    Note: For example, a supercell size, a finite-difference displacement, a broadening width, or the spin-spin coupling constant of an NMR calculation.

    name*

    The designation of the calculation parameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    value*

    The data associated with the calculation parameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no any any any —
    unit

    The unit in which the associated value is expressed.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: A symbol from the MatCore Unit Table (Annex U), or the reserved symbol dimensionless. If and only if no Annex U symbol applies, a string prefixed x-gnu: giving a GNU Units expression (accepted with a validation warning).

    Note: Give it when the type of the value is float or int; omit it when it is string or bool.

    description

    An explanation of the meaning, source, or purpose of the calculation parameter.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Example: Derived Property Metadata

    Dataset source: https://archive.materialscloud.org/record/2024.116

    {
  "derived": {
    "settings": [
      {
        "computation-label": [
          "raman"
        ],
        "derived-property": [
          {
            "type": "Spectroscopy, vibrational",
            "name": "Raman spectrum",
            "description": "Raman spectra plots of intensity versus wavenumber (frequency) representing inelastic light scattering (Raman effect) from a sample.",
            "procedure": "The Raman spectra is obtained in two steps: (1) Phonon eigenmodes and frequencies are computed for a given crystalline material within the harmonic approximation using force constants derived from density functional theory (DFT). (2) The Raman tensor is obtained by numerically differentiating the electronic susceptibility with respect to atomic displacements along each vibrational mode and using these tensors to compute Raman scattering intensities for all Raman-active modes, ultimately yielding a full Raman spectrum after appropriate averaging and broadening."
          }
        ]
      }
    ]
  }
}
