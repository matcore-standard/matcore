# MatCore

**Material Core (MatCore)** is a metadata standard for computational materials science. MatCore represents key aspects of a material-focused computation to make it understandable to the broad materials research community. It provides pragmatic and workable guidelines for documentation of materials data.

MatCore is developed as a grassroots effort by experts in first principles calculations (DFT, GW), molecular dynamics, phase field, machine learning for materials, and related fields.
