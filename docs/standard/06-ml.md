# 2.5 ML

\* = required property

### `ml-task*`

Characterization of the machine learning process performed.

**Repeatable:** True

*Values (legacy text):* Contains SubProperties as listed below.

#### `type*`

The nature of the machine learning task.

**Repeatable:** True

*Values (legacy text):* String containing one of the following values: "Property prediction" "Structure prediction" (e.g. crystal structure prediction) "Structure generation" (e.g. de novo crystal generation) "Synthesis prediction" "Material ranking" "Clustering" "Embedding" Other user-specified value if none of the above apply.

> Note:This Property can be repeated if the machine learning task involves multiple types of calculations.

#### `description`

Explanation of the machine learning task performed.

**Repeatable:** False

*Values (legacy text):* A string containing a more detailed explanation of the machine learning task and its objectives.

### `ml-model*`

A comprehensive description of the machine learning approach and architecture used.

**Repeatable:** False

*Values (legacy text):* Contains SubProperties as listed below.

#### `algorithm*`

The machine learning method used.

**Repeatable:** False

*Values (legacy text):* A string containing a description of the machine learning algorithm used (e.g. neural network, random forest, Gaussian process, etc.)

#### `target-variable*`

The desired output or answer the machine learning model aims to predict.

**Repeatable:** True

*Values (legacy text):* A string containing a description of a target variable the machine learning model aims to predict.

#### `input-feature`

Information provided to the machine learning method.

**Repeatable:** True

*Values (legacy text):* A string containing a description of the form and meaning of an input variable/feature provided to the machine learning model (e.g. a graph representation of a crystal structure). This can include information on feature engineering performed to define the input (e.g. dimensionality reduction, clustering, etc.).

#### `model-architecture`

A description of the network topology used by the specified algorithm.

**Repeatable:** False

*Values (legacy text):* A string containing a description of the model architecture used by the specified algorithm (e.g. for a neural network: the number of layers, nodes per layer, etc.).

#### `model-size`

A measure of the magnitude of the machine learning architecture.

**Repeatable:** False

*Values (legacy text):* A string containing a description of the size of the trained model (e.g. number of parameters, storage space, memory requirements, etc.)

### `training-data`

The information used for parameterizing the machine learning model.

**Repeatable:** True

*Values (legacy text):* Contains SubProperties as listed below.

#### `name*`

Name of the training dataset used to train in the machine learning model.

**Repeatable:** False

*Values (legacy text):* String containing the dataset name.

#### `contents*`

Description of the information included in the training dataset.

**Repeatable:** False

*Values (legacy text):* String containing a description of the training data (e.g. DFT calculations, experiments, etc.)

#### `source`

Location from which the training data was obtained.

**Repeatable:** False

*Values (legacy text):* A string containing a MatCore ID, web address, DOI, citation, or other description of the source of the training data.

#### `size`

Number of items in the training dataset.

**Repeatable:** False

*Values (legacy text):* A string containing information on the number of data points, configurations, etc., in the training set.

#### `data-preprocessing`

Approach used for preliminary refining of raw, unformatted, or incomplete information into a structured and clean state suitable for modeling or analysis.

**Repeatable:** False

*Values (legacy text):* A string containing a description of any preprocessing applied to the dataset to prepare it for training the machine learning model.

#### `missing-data`

Documentation of incomplete, null, or unrecorded entries within a feature set that hinder algorithm training.

**Repeatable:** False

*Values (legacy text):* A description of missing entries in the raw dataset (e.g. percentage of missing data and explanation of which fields are missing and why).

#### `missing-data-strategy`

Approach used for filling in or removing blank, null, or unknown entries in a dataset.

**Repeatable:** False

*Values (legacy text):* A string describing the approach used for handling missing data.

#### `outlier-handling`

Approach to identifying and addressing extreme observations that deviate significantly from the general distribution to ensure they do not disproportionately skew model training.

**Repeatable:** False

*Values (legacy text):* A string containing the method used to detect and handle outliers.

#### `dataset-split`

A description of how information used to train the machine learning model was divided into subsets as part of the training process.

**Repeatable:** False

*Values (legacy text):* A string containing information about how the dataset was split into train/validation/test ratios, and any other relevant information related to how the dataset was distributed in the training process.

### `training-method`

The approach used to determine the machine learning model's free parameters.

**Repeatable:** False

*Values (legacy text):* Contains SubProperties as listed below.

#### `training-procedure*`

The methodology used to determine the machine learning model's free parameters.

**Repeatable:** False

*Values (legacy text):* A string containing a description of the procedure used to train the machine learning model.

#### `training-hyperparameters`

Documentation of the settings used in fitting the model.

**Repeatable:** False

*Values (legacy text):* A string describing the hyperparameters used in the training of the model (e.g. learning rate, early-stopping, etc.)

#### `transfer-learning`

Method used to migrate knowledge from previously mastered objectives to accelerate proficiency for the current machine learning task.

**Repeatable:** False

*Values (legacy text):* A string containing details of the transfer learning methods used (such as fine-tuning, domain adaptation, multi-task learning, delta learning, etc.).

### `model-performance`

An assessment of the reliability of the machine learning results.

**Repeatable:** False

*Values (legacy text):* Contains SubProperties as listed below.

#### `validation*`

A description of the approach used to determine the reliability of the obtained machine learning results.

**Repeatable:** True

*Values (legacy text):* A string containing a description of the validation method used (e.g. k-fold cross-validation, hold-out set, etc.) and associated validation measure (e.g. MAE, RMSE, R^2, etc.).

#### `uncertainty-quantification`

The method or process used to identify and measure the range of possible outcomes to assess the reliability of machine learning model predictions.

**Repeatable:** False

*Values (legacy text):* A string containing a description of the method used to assess uncertainty of the machine learning method outputs (e.g. Bayesian methods, dropout, ensemble methods, Gaussian process, etc.)

### `interpretability-method`

A technique used to understand the cause-and-effect relationships within the machine learning model's inputs and outputs.

**Repeatable:** False

*Values (legacy text):* A string containing details of the approach and results of the interpretability analysis (e.g. feature importance, global surrogate models, LIME (Local Interpretable Model-agnostic Explanations), SHAP (SHapley Additive exPlanations), Saliency Maps, etc.)
