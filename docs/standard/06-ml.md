The nature of the machine learning task.

| Required | Repeatable | Type | Extent | Kind | Rec. unit |
|---|---|---|---|---|---|
| yes | yes | string | [] | inapplicable | — |

Recommended: `Property prediction`, `Structure generation`, `Synthesis prediction`, `Ranking`, `Clustering`, `Embedding`. Other values are allowed.

**Clarifications:** "Property prediction" – Values of a property predicted for given materials or structures, e.g. formation energies or band gaps. "Structure generation" – New structures produced by the model, freely or for a given composition, space group or target property, including crystal structure prediction for a given composition. "Synthesis prediction" – Routes, precursors or conditions predicted for making a given material. "Ranking" – Given materials or structures ordered by a predicted score, e.g. to select candidates for further calculation. "Clustering" – Given materials or structures grouped by similarity. "Embedding" – A numerical representation computed for each given material or structure, for use by other models or analyses.

Note: This Property can be repeated if the machine learning task involves multiple types of calculations.

Note: A machine-learned interatomic potential is not described here; it is a particle interaction model (pim, theory-level Machine-learned).
