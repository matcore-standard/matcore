# MatCore Standard Revisions

<p class="mc-version" data-version="0.6.0">Version 0.6.0</p>

| Version | Date | Change Type | Section(s) | Description of Change | Approved By |
|---|---|---|---|---|---|
| 0.6.0 | 08-Nov-2026 | Minor (Breaking) | Across document | - DFT section complete: every property has a type, extent, Kind, recommended unit and structured values<br> - Structure and composition: a material component is described by one chemical formula (with variables, groups and user-defined species) and by its form, role, fraction and phase; isomers and polymorphs are identified by InChI, SMILES or AFLOW prototype labels<br> - Simulation conditions: every condition is defined as imposed; a varying value is given as qualified entries (initial, final, average, minimum, maximum); the simulation type is classified by thermodynamic state, openness, time dependence and spatial uniformity; added electric and magnetic fields, body force, electrode potential and chemical potential; number density removed<br> - Software: one entry per layer (simulation code, calculation method, workflow framework, script), with exact identification, dependencies and build options; files carry an encoding and checksums<br> - Added publication, dataset location and the author of the metadata record; licenses as SPDX identifiers with name, link and scope; provenance agents described like creators<br> - Pure numbers are written without a unit; generic parameters defined in the Preamble<br> - Annex U gains four Kinds and five units; Annex I gains InChI, SMILES and AFLOW<br> - Preamble: goals of FAIR data and AI readiness, acronyms defined, methods that supply energies and forces distinguished, and the order of array values<br> - Renaming of some properties (e.g. citation to publication, pseudopotential to pseudopotential-or-paw, method to method-density) | E. B. Tadmor |
| 0.5.0 | 04-Nov-2026 | Minor (Breaking) | Across document | - Minimal section complete: every property has a type, extent, Kind, recommended unit and structured values<br> - Every numerical value is written as a value with its unit; pure numbers use the unit dimensionless<br> - Added Annex I, Identifier Schemes; creators, contributors, affiliations and funders carry scheme-tagged identifiers<br> - Renaming of some properties (e.g. phase to phases, links to link, comments to comment)<br> - Restructured properties (e.g. funder as a name and an identifier, checksum with its algorithm)<br> - Preamble: rules for units, Type, Extent, Kind and Recommended unit; the original list nesting restored<br> - Corrections to unit symbols and property names, and to text lost in the migration from the Google Doc | E. B. Tadmor |
| 0.4.0 | 01-Nov-2026 | Minor (Breaking) | Across document | - Standard moved from the Google Doc to the GitHub repository and website; the YAML schema is the source of truth<br> - Renaming of some properties (e.g. material to material-component)<br> - Added Annex U, the MatCore Unit Table<br> - Section introductions and examples shown with each section | E. B. Tadmor |
| 0.3.0 | 06-Apr-2026 | Minor (Breaking) | Across document | - Added phase field method standard<br> - Changed from JSON to XML for examples<br> - Replaced key-value-unit lists with nested sub-properties | E. B. Tadmor |
| 0.2.0 | 19-Mar-2026 | Minor (Breaking) | Across document | Changes based on MatCore Standard Committee review:<br> - Renaming of some properties<br> - Addition of properties<br> - Changes to property definitions and controlled vocabulary | E. B. Tadmor |
