    2.4 Many-Body Perturbation Theory (MBPT) Metadata

    Version 0.4.0

    The metadata for Many-Body Perturbation Theory (MBPT) data (MatCore-MBPT) is tabulated below. This includes the MBPT method, starting point, dielectric treatment, and associated parameters. (Note: This standard inherits the metadata in the minimal MatCore standard and MatCore-DFT standard, adding the properties below.)

    * required appears at most once repeatable

    mbpt-method*

    The many-body perturbation theory (MBPT) approach used and associated settings.

    Required Repeatable
    yes no
    type*

    The nature of the MBPT calculation performed.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: String containing one of the following values: "GW" "BSE" "GW/BSE" Other user-specified value if none of the above apply.

    self-consistency*

    Specifies the level of iterative updating applied to the Green's function (G), the screened Coulomb interaction (W), or the excitonic Hamiltonian during the calculation. This property identifies whether the MBPT equations are solved in a 'one-shot' perturbative manner or through an iterative cycle where the electronic or excitonic quasiparticle states are updated to reach a self-consistent solution.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: String containing one of the following values depending on the variant of the GW, BSE, or GW/BSE approach used: "G0W0" – One-shot calculation; the G and *W *are constructed using the starting eigenvalues and wavefunctions. "GW0" – Only the Green's function G is updated iteratively, while *W *remains fixed at the *W0 *level "G0W" – Only the screened interaction W is updated iteratively, while G remains fixed at G0 "scGW" – Fully self-consistent GW; bothG* and W are updated iteratively until the quasiparticle energies and/or wavefunctions converge "QSGW" – Quasiparticle self-consistent GW; the starting potential is updated to provide the optimal independent particle basis for the GW expansion "BSE0" – One-shot BSE; the excitonic Hamiltonian is built once using fixed GW quasiparticle energies and screening (W) "scBSE" – Self-consistent BSE; internal refinement of the kernel or energies within the BSE process "evGW+BSE" – Eigenvalue-only self-consistent GW (evGW) used as the starting point for a subsequent BSE calculation "scGW+BSE" – The BSE is solved using the results of a fully self-consistent GW calculation Other user-specified value if none of the above apply.

    starting-point*

    The density functional theory (DFT) exchange-correlation functional used to generate Kohn-Sham wavefunctions and eigenvalues for the Green's function and the screened Coulomb interaction.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: String containing one of the following values: "LDA" "GGA" "Meta GGA" "Hybrid GGA" "DFT+U" Other user-specified value if none of the above apply.

    dielectric-matrix*

    Information on the dielectric matrix used to compute the screened Coulomb interaction W.

    Required Repeatable
    yes no
    planewave-basis-cutoff

    For a planewave code, the basis set cutoff employed for the dielectric matrix. This is the same as the kinetic energy cutoff.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: A real number containing the cutoff. Legacy unit: Rydberg (Ry)

    Note:Specify either "planewave-basis-cutoff" or "local-orbital-basis-set", but not both.

    local-orbital-basis-set

    For local orbital codes, the name of the basis set .

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: A string containing the name of the atomic orbital basis. (e.g. "cc-pV6Z").

    Note:Specify either "basis-cutoff-planewave" or "local-orbital-basis-set", but not both.

    frequency

    The method used to handle the frequency dependence of the Green's function, the screened Coulomb interaction, and their product.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: String containing one of the following values: "Hybertsen-Louie" "Godby-Needs" "Full frequency real axis" "Full frequency imaginary axis" "Contour deformation" "Spacetime" Other user-specified value if none of the above apply.

    response-basis-size

    For sum-over-states methods, the number of bands used in the sum. For linear-response methods, the number of dielectric eigenvalues.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: One integer containing the number of bands or eigenvalues. Legacy unit: dimensionless

    q-points*

    Brillouin zone grid used for sampling the dielectric matrix.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: Ordered list of 3 integer numbers containing the number points along the three reciprocal lattice vector directions. Legacy unit: dimensionless

    coulomb-truncation

    Method used to eliminate long-range Coulomb interactions between periodic replicas in supercell calculations.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: String containing one of the following values: "Ismail-Beigi" "Rozzi" "Spencer-Alavi" Other user-specified value if none of the above apply.

    gw-bands

    Number of bands for which the GW correction is evaluated.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: One integer specifying how many bands are corrected, counting from the bottom of the valence bands. Legacy unit: dimensionless

    bse-hamiltonian

    A collective descriptor for the parameters defining the construction, dimensionality, and solution method of the effective excitonic Bethe-Salpeter Hamiltonian that is being solved in a BSE calculation. It characterizes the Hilbert space size and the physical constraints (momentum and spin) applied during the diagonalization

    Required Repeatable
    no no
    number-valence-bands

    Number of valence bands included in the BSE Hamiltonian.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: One integer specifying how many valence bands are corrected, counting from the valence band top. Legacy unit: dimensionless

    number-conduction-bands

    Number of conduction bands included in the BSE Hamiltonian.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: One integer specifying how many bands are corrected, counting from the conduction band bottom. Legacy unit: dimensionless

    k-point-mesh

    Brillouin zone grid used for building the BSE Hamiltonian.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: Ordered list of 3 integer numbers containing the number points along the reciprocal lattice vector directions. Legacy unit: dimensionless

    exciton-momentum

    Crystal momentum of the exciton in the BSE calculation.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: Ordered list of 3 real values containing the crystal momentum, e.g. [0.5,0.5,1.0]. Legacy unit: Reciprocal lattice units (2π/a)

    exciton-multiplicity

    Specification whether the BSE calculation is performed for singlet or triplet excitons.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: string containing one of the values: "Singlet" "Triplet" Other user-specified value if none of the above apply.

    diagonalization

    Approximation method used to diagonalize the BSE Hamiltonian.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: String containing one of the following values: "Tamm-Dancoff" "Full diagonalization" Other user-specified value if none of the above apply.

    number-lowest-eigenvalues

    Number of lowest eigenvalues computed by solving the BSE Hamiltonian.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: One integer containing the number of BSE eigenvalues. Legacy unit: dimensionless

    bse-kernel-truncation

    Method used to eliminate long-range Coulomb interactions between periodic replicas in the BSE Coulomb kernel.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: String containing one of the following values: "Ismail-Beigi" "Rozzi" "Spencer-Alavi" Other user-specified value if none of the above apply.
