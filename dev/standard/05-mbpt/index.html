    2.5 Many-Body Perturbation Theory (MBPT) Metadata

    Version 0.7.0

    The metadata for Many-Body Perturbation Theory (MBPT) data (MatCore-MBPT) is tabulated below. This includes the MBPT method, dielectric treatment, and associated parameters. The properties are given in settings blocks, each naming the MBPT computations it describes. (Note: This standard inherits the metadata in the minimal MatCore standard, adding the properties below. The DFT computation an MBPT computation starts from is described by MatCore-DFT and named in its input with the role Starting point.)

    * required appears at most once repeatable

    settings*

    Settings shared by the computations named in it.

    Required Repeatable
    yes yes
    computation-label*

    The label of a computation these settings apply to.

    Required Repeatable Type Extent Kind Rec. unit
    yes yes string [] inapplicable —
    mbpt-method*

    The many-body perturbation theory (MBPT) approach used and associated settings.

    Required Repeatable
    yes no
    type*

    The nature of the MBPT calculation performed.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: GW, BSE, GW/BSE. Other values are allowed.

    Clarifications:

    • "GW" – A GW calculation of quasiparticle energies
    • "BSE" – A BSE calculation of neutral excitations from given quasiparticle energies, e.g. DFT energies with a scissor shift, the computation they come from named in minimal computation › input with the role Starting point
    • "GW/BSE" – A GW calculation followed by a BSE calculation using its results, described as one computation
    gw-self-consistency

    Specifies the level of iterative updating applied to the Green's function (G) and the screened Coulomb interaction (W) in the GW calculation. This property identifies whether the GW equations are solved in a 'one-shot' perturbative manner or through an iterative cycle where the quasiparticle states are updated to reach a self-consistent solution.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: G0W0, GW0, G0W, evGW, scGW, QSGW. Other values are allowed.

    Clarifications:

    • "G0W0" – One-shot calculation; G₀ and W₀ are constructed using the starting eigenvalues and wavefunctions
    • "GW0" – Only the Green's function G is updated iteratively, while W remains fixed at W₀
    • "G0W" – Only the screened interaction W is updated iteratively, while G remains fixed at G₀
    • "evGW" – Eigenvalue-only self-consistent GW; the quasiparticle energies are updated iteratively in both G and W, while the wavefunctions are kept from the starting point
    • "scGW" – Fully self-consistent GW; both G and W are updated iteratively until the quasiparticle energies and wavefunctions converge
    • "QSGW" – Quasiparticle self-consistent GW; the starting potential is updated to provide the optimal independent particle basis for the GW expansion

    Note: Give it when type is GW or GW/BSE.

    bse-self-consistency

    Specifies the level of iterative updating applied to the excitonic Hamiltonian in the BSE calculation. This property identifies whether the BSE is solved in a 'one-shot' manner or through an iterative cycle where the excitonic states are updated to reach a self-consistent solution.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: BSE0, scBSE. Other values are allowed.

    Clarifications:

    • "BSE0" – One-shot BSE (BSE₀); the excitonic Hamiltonian is built once using fixed quasiparticle energies and screening (W)
    • "scBSE" – Self-consistent BSE; internal refinement of the kernel or energies within the BSE process

    Note: Give it when type is BSE or GW/BSE.

    dielectric-matrix*

    Information on the dielectric matrix used to compute the screened Coulomb interaction W.

    Required Repeatable
    yes no
    planewave-basis-cutoff

    For a planewave code, the basis set cutoff employed for the dielectric matrix. It is set separately from the cutoff of the wave functions (dft kinetic-energy-cutoff) and is usually lower.

    Required Repeatable
    no no

    Note: Specify either "planewave-basis-cutoff" or "localized-orbital-basis-set", but not both.

    value*

    The value of the property, in the unit given by unit.

    Required Repeatable Type Extent Kind Rec. unit
    yes no float [] Energy eV

    Minimum: 0.

    unit*

    The unit of the value, an Annex U symbol whose Kind is the Kind of value.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    localized-orbital-basis-set

    For local orbital codes, the name of the basis set.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Examples: cc-pV6Z.

    Note: Specify either "planewave-basis-cutoff" or "localized-orbital-basis-set", but not both.

    frequency

    The method used to handle the frequency dependence of the Green's function, the screened Coulomb interaction, and their product.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Hybertsen-Louie, Godby-Needs, Full frequency real axis, Full frequency imaginary axis, Contour deformation, Spacetime. Other values are allowed.

    Clarifications:

    • "Hybertsen-Louie" – Generalized plasmon-pole model fitted to the static dielectric matrix and the f-sum rule
    • "Godby-Needs" – Plasmon-pole model fitted to the dielectric matrix at zero frequency and at one imaginary frequency
    • "Full frequency real axis" – The dielectric matrix is computed on a grid of real frequencies and the frequency integral evaluated on the real axis
    • "Full frequency imaginary axis" – The dielectric matrix is computed on the imaginary axis and the self-energy continued analytically to real frequencies
    • "Contour deformation" – The frequency integral is evaluated along the imaginary axis plus the residues of the poles it encloses
    • "Spacetime" – The Green's function and the screened interaction are computed in real space and imaginary time
    response-basis-size

    For sum-over-states methods, the number of bands used in the sum. For linear-response methods, the number of dielectric eigenvalues.

    Required Repeatable Type Extent Kind Rec. unit
    no no int [] dimensionless —

    Minimum: 1.

    band-terminator

    The method used to approximate the contribution of the bands left out of the sum over states of the polarizability.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: None, Bruneval-Gonze. Other values are allowed.

    Clarifications:

    • "None" – No correction; the sum stops at its last band
    • "Bruneval-Gonze" – The bands left out are replaced by one effective energy (the extrapolar approximation)
    q-points*

    Brillouin zone grid used for sampling the dielectric matrix.

    Required Repeatable Type Extent Kind Rec. unit
    yes no int [3] dimensionless —

    Minimum: 1, for each component.

    Clarifications: Ordered list of three integers, the number of points along the three reciprocal lattice vector directions.

    coulomb-truncation

    Method used to eliminate long-range Coulomb interactions between periodic replicas in supercell calculations.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Ismail-Beigi, Rozzi, Spencer-Alavi. Other values are allowed.

    Clarifications:

    • "Ismail-Beigi" – Truncation for systems periodic in one or two dimensions (wires, slabs)
    • "Rozzi" – Exact cutoff for systems periodic in zero, one or two dimensions (molecules, wires, slabs)
    • "Spencer-Alavi" – Truncation of the Coulomb interaction beyond a sphere
    self-energy

    The settings of the GW self-energy and the bands it corrects.

    Required Repeatable
    no no

    Note: Give it when type is GW or GW/BSE.

    band-range

    The first and last band whose quasiparticle energies are computed. Bands are numbered from 1, the lowest band in the calculation.

    Required Repeatable Type Extent Kind Rec. unit
    no no int [2] dimensionless —

    Minimum: 1, for each component. Examples: [35, 70].

    number-of-bands

    The number of bands in the sum over states of the self-energy, which runs over bands 1 to number-of-bands. It is at least the last band of band-range.

    Required Repeatable Type Extent Kind Rec. unit
    no no int [] dimensionless —

    Minimum: 1.

    band-terminator

    The method used to approximate the contribution of the bands left out of the sum over states of the self-energy.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: None, Bruneval-Gonze. Other values are allowed.

    Clarifications:

    • "None" – No correction; the sum stops at its last band
    • "Bruneval-Gonze" – The bands left out are replaced by one effective energy (the extrapolar approximation)
    bse-hamiltonian

    A collective descriptor for the parameters defining the construction, dimensionality, and solution method of the effective excitonic Bethe-Salpeter Hamiltonian that is being solved in a BSE calculation. It characterizes the Hilbert space size and the physical constraints (momentum and spin) applied during the diagonalization.

    Required Repeatable
    no no

    Note: Give it when type is BSE or GW/BSE.

    number-valence-bands

    Number of valence bands included in the BSE Hamiltonian.

    Required Repeatable Type Extent Kind Rec. unit
    no no int [] dimensionless —

    Minimum: 1.

    Clarifications: Counted downward from the valence band top.

    number-conduction-bands

    Number of conduction bands included in the BSE Hamiltonian.

    Required Repeatable Type Extent Kind Rec. unit
    no no int [] dimensionless —

    Minimum: 1.

    Clarifications: Counted upward from the conduction band bottom.

    k-point-mesh

    Brillouin zone grid used for building the BSE Hamiltonian.

    Required Repeatable Type Extent Kind Rec. unit
    no no int [3] dimensionless —

    Minimum: 1, for each component.

    Clarifications: The number of points along each reciprocal lattice vector of the cell in minimal conditions › cell.

    exciton-momentum

    Crystal momentum of the exciton in the BSE calculation.

    Required Repeatable Type Extent Kind Rec. unit
    no no float [3] dimensionless —

    Examples: [0.5, 0.5, 1.0].

    Clarifications: The exciton's center-of-mass crystal momentum Q = Q₁b₁ + Q₂b₂ + Q₃b₃, where b₁, b₂, b₃ are the reciprocal lattice vectors of the cell in minimal conditions › cell; the value gives Q₁, Q₂, Q₃. [0, 0, 0] is the optical limit. Give the exciton's momentum, not an input shift that a code may define with the opposite sign.

    exciton-multiplicity

    Specification whether the BSE calculation is performed for singlet or triplet excitons.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Singlet, Triplet. Other values are allowed.

    Clarifications:

    • "Singlet" – Spin-singlet excitons; the kernel includes the exchange term
    • "Triplet" – Spin-triplet excitons; the exchange term vanishes
    diagonalization

    Approximation method used to diagonalize the BSE Hamiltonian.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Tamm-Dancoff, Full diagonalization. Other values are allowed.

    Clarifications:

    • "Tamm-Dancoff" – Only the resonant block of the Hamiltonian is kept; its coupling to the antiresonant block is neglected
    • "Full diagonalization" – The resonant and antiresonant blocks and the coupling between them are kept

    The term names the approximation, not the solver (direct or iterative).

    number-lowest-eigenvalues

    Number of lowest eigenvalues computed by solving the BSE Hamiltonian.

    Required Repeatable Type Extent Kind Rec. unit
    no no int [] dimensionless —

    Minimum: 1.

    bse-kernel-truncation

    Method used to eliminate long-range Coulomb interactions between periodic replicas in the BSE Coulomb kernel.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Ismail-Beigi, Rozzi, Spencer-Alavi. Other values are allowed.

    Clarifications:

    • "Ismail-Beigi" – Truncation for systems periodic in one or two dimensions (wires, slabs)
    • "Rozzi" – Exact cutoff for systems periodic in zero, one or two dimensions (molecules, wires, slabs)
    • "Spencer-Alavi" – Truncation of the Coulomb interaction beyond a sphere

    Note: Give it when type is BSE or GW/BSE.
