    2.6 Machine Learning (ML) Metadata

    Version 0.9.0

    The metadata for Machine Learning (ML) data (MatCore-ML) is tabulated below. This metadata documents key aspects of the ML method to provide understanding of the dataset generated by it. The properties are given in settings blocks, each naming the ML computations it describes. (Note: This standard inherits the metadata in the minimal MatCore standard, adding the properties below.)

    * required appears at most once repeatable

    settings*

    Settings shared by the computations named in it.

    Required Repeatable
    yes yes
    computation-label*

    The label of a computation these settings apply to.

    Required Repeatable Type Extent Kind Rec. unit
    yes yes string [] inapplicable —
    ml-task*

    Characterization of the machine learning process performed.

    Required Repeatable
    yes no
    type*

    The nature of the machine learning task.

    Required Repeatable Type Extent Kind Rec. unit
    yes yes string [] inapplicable —

    Recommended: Property prediction, Structure generation, Synthesis prediction, Ranking, Clustering, Embedding. Other values are allowed.

    Clarifications:

    • "Property prediction" – Values of a property predicted for given materials or structures, e.g. formation energies or band gaps
    • "Structure generation" – New structures produced by the model, freely or for a given composition, space group or target property, including crystal structure prediction for a given composition
    • "Synthesis prediction" – Routes, precursors or conditions predicted for making a given material
    • "Ranking" – Given materials or structures ordered by a predicted score, e.g. to select candidates for further calculation
    • "Clustering" – Given materials or structures grouped by similarity
    • "Embedding" – A numerical representation computed for each given material or structure, for use by other models or analyses

    Note: This Property can be repeated if the machine learning task involves multiple types of calculations.

    Note: A machine-learned interatomic potential is not described here; it is a particle interaction model (pim, theory-level Machine-learned).

    Note: Structures generated by a model learned from data are described here, guided or not. Structures built by rules the author specifies, with no such model, are a computation of method GC.

    description

    Explanation of the machine learning task performed.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —
    ml-model*

    A comprehensive description of the machine learning approach and architecture used.

    Required Repeatable
    yes no

    Note: An inference computation whose model is trained in another computation of the record gives only algorithm and target-variable, to identify the model; the training computation's settings describe the rest.

    algorithm*

    The machine learning method used.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Examples: Neural network, Random forest, Gaussian process.

    target-variable*

    The desired output or answer the machine learning model aims to predict.

    Required Repeatable Type Extent Kind Rec. unit
    yes yes string [] inapplicable —
    input-feature

    Information provided to the machine learning method.

    Required Repeatable Type Extent Kind Rec. unit
    no yes string [] inapplicable —

    Clarifications: The form and meaning of an input variable or feature, e.g. a graph representation of a crystal structure, including any feature engineering performed to define it (e.g. dimensionality reduction, clustering).

    model-architecture

    A description of the network topology used by the specified algorithm.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: E.g. for a neural network, the kinds of layers and how they are connected. Explain the role of each architecture-parameter entry.

    architecture-parameter

    A fixed variable that defines the architecture of the machine learning model.

    Required Repeatable
    no yes

    Note: For example, the number of layers, the number of nodes per layer, a cutoff radius or a maximum body order. Training settings are hyperparameter entries of training-method.

    name*

    The designation of the architecture parameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    value*

    The data associated with the architecture parameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no any any any —
    unit

    The unit in which the associated value is expressed.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: A symbol from the MatCore Unit Table (Annex U), or the reserved symbol dimensionless. If and only if no Annex U symbol applies, a string prefixed x-gnu: giving a GNU Units expression (accepted with a validation warning).

    Note: Give it when the type of the value is float or int; omit it when it is string or bool.

    description

    An explanation of the meaning, source, or purpose of the architecture parameter.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —
    model-size

    The number of trainable parameters of the machine learning model.

    Required Repeatable Type Extent Kind Rec. unit
    no no int [] dimensionless —

    Minimum: 1.

    training-data

    The information used for parameterizing the machine learning model.

    Required Repeatable
    no yes
    name*

    Name of the training dataset used to train in the machine learning model.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    contents*

    Description of the information included in the training dataset.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Clarifications: E.g. DFT calculations or experiments, and what one item of the data is (a structure, a configuration), since size counts items.

    source

    Location from which the training data was obtained.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: A MatCore ID, web address, DOI, citation, or other description of where the data was obtained. Training data produced by a computation of the record is not given here: the training computation names it in minimal computation › input with the role Training data.

    size

    Number of items in the training dataset.

    Required Repeatable Type Extent Kind Rec. unit
    no no int [] dimensionless —

    Minimum: 1.

    Clarifications: The kind of item is stated in contents.

    data-preprocessing

    Approach used for preliminary refining of raw, unformatted, or incomplete information into a structured and clean state suitable for modeling or analysis.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —
    missing-data

    Documentation of incomplete, null, or unrecorded entries within a feature set that hinder algorithm training.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: E.g. the percentage of missing data, and which fields are missing and why.

    missing-data-strategy

    Approach used for filling in or removing blank, null, or unknown entries in a dataset.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —
    outlier-handling

    Approach to identifying and addressing extreme observations that deviate significantly from the general distribution to ensure they do not disproportionately skew model training.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —
    dataset-split

    A description of how information used to train the machine learning model was divided into subsets as part of the training process.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: In words, e.g. a random split of 80/10/10 into training, validation and test sets, a split stratified by composition, or k-fold cross-validation.

    training-method

    The approach used to determine the machine learning model's free parameters.

    Required Repeatable
    no no
    training-procedure*

    The methodology used to determine the machine learning model's free parameters.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Clarifications: E.g. the optimizer (Adam, L-BFGS, closed-form least squares), the learning-rate schedule, the stopping rule, and any active-learning loop with its selection criterion (e.g. query by committee, an uncertainty threshold). Explain the role of each hyperparameter entry.

    loss-function

    The quantities fitted in training and how they are weighted.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: E.g. the mean squared error of formation energies, or a weighted sum of the errors in energies, forces and stresses with weights 1:100:10.

    hyperparameter

    A fixed variable that controls the fitting of the machine learning model.

    Required Repeatable
    no yes

    Note: For example, the learning rate, the batch size, the number of epochs or the early-stopping patience. Numbers that fix the model's architecture are architecture-parameter entries of ml-model.

    name*

    The designation of the hyperparameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    value*

    The data associated with the hyperparameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no any any any —
    unit

    The unit in which the associated value is expressed.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: A symbol from the MatCore Unit Table (Annex U), or the reserved symbol dimensionless. If and only if no Annex U symbol applies, a string prefixed x-gnu: giving a GNU Units expression (accepted with a validation warning).

    Note: Give it when the type of the value is float or int; omit it when it is string or bool.

    description

    An explanation of the meaning, source, or purpose of the hyperparameter.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —
    transfer-learning

    Method used to migrate knowledge from previously mastered objectives to accelerate proficiency for the current machine learning task.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: E.g. fine-tuning, domain adaptation, multi-task learning or delta learning, with the details of how it was applied.

    model-performance

    An assessment of the reliability of the machine learning results.

    Required Repeatable
    no no
    evaluation-method*

    A description of the approach used to determine the reliability of the obtained machine learning results.

    Required Repeatable Type Extent Kind Rec. unit
    yes yes string [] inapplicable —

    Clarifications: E.g. a hold-out test set or k-fold cross-validation. Validation data serve to tune the model's hyperparameters or stop its training; test data, used for neither, assess it. The scores are metric entries.

    metric

    A score of the machine learning model on one subset of the data.

    Required Repeatable
    no yes
    subset*

    The data on which the score was measured.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: Training, Validation, Test. Other values are allowed.

    Clarifications:

    • "Training" – The data the model's parameters were fitted to
    • "Validation" – Data used to tune hyperparameters or to stop training
    • "Test" – Data used in neither, which assesses the model
    quantity*

    The target variable the score is for.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Examples: Formation energy, Forces.

    measure*

    The statistic used as the score.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: MAE, RMSE, R², Accuracy. Other values are allowed.

    Clarifications:

    • "MAE" – Mean absolute error
    • "RMSE" – Root-mean-square error
    • "R²" – Coefficient of determination
    • "Accuracy" – Fraction of correct predictions, for a classification
    value*

    The value of the property, in the unit given by unit.

    Required Repeatable Type Extent Kind Rec. unit
    yes no float [] any —
    unit*

    The unit in which the associated value is expressed.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Clarifications: A symbol from the MatCore Unit Table (Annex U), or the reserved symbol dimensionless. If and only if no Annex U symbol applies, a string prefixed x-gnu: giving a GNU Units expression (accepted with a validation warning).

    normalized-by

    What each value is divided by.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Atom, Formula unit, Cell volume. Other values are allowed.

    Clarifications:

    • "Atom" – Divided by the number of atoms in the configuration
    • "Formula unit" – Divided by the number of formula units in the configuration
    • "Cell volume" – Divided by the volume of the cell

    Note: Omit it for a value not divided by anything. The unit is that of the undivided quantity, e.g. eV for a total energy divided by the number of atoms.

    uncertainty-quantification

    The method or process used to identify and measure the range of possible outcomes to assess the reliability of machine learning model predictions.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: E.g. Bayesian methods, dropout, ensemble methods or a Gaussian process. Say whether an uncertainty for each item is part of the dataset.

    applicability-domain

    Where the inputs the model is applied to lie relative to its training data.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: E.g. the elements, structure types or range of compositions the training data cover, and how inputs outside them were identified (a distance in feature space, an uncertainty threshold).

    interpretability-method

    A technique used to understand the cause-and-effect relationships within the machine learning model's inputs and outputs.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: The approach and results of the interpretability analysis, e.g. feature importance, global surrogate models, LIME (Local Interpretable Model-agnostic Explanations), SHAP (SHapley Additive exPlanations) or saliency maps.

    inference

    How the dataset was produced from the machine learning model.

    Required Repeatable
    no no

    Note: Give it for a computation that applies a trained model, e.g. one whose task is Structure generation or Property calculation.

    input-data

    What the machine learning model was applied to.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: E.g. a list of candidate compositions or a screening set of structures. Data from a computation of the record is named in minimal computation › input instead, e.g. with the role Source data.

    conditioning

    The targets imposed on a generative model's outputs.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: E.g. a space group, a composition or a range of a property.

    sampling-procedure

    How the outputs were drawn from the machine learning model.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: E.g. autoregressive sampling at a given temperature, beam search, or one prediction per input. Explain the role of each inference-parameter entry.

    inference-parameter

    A fixed variable that controls the application of the machine learning model.

    Required Repeatable
    no yes

    Note: For example, the sampling temperature, the number of samples drawn or the beam width.

    name*

    The designation of the inference parameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    value*

    The data associated with the inference parameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no any any any —
    unit

    The unit in which the associated value is expressed.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: A symbol from the MatCore Unit Table (Annex U), or the reserved symbol dimensionless. If and only if no Annex U symbol applies, a string prefixed x-gnu: giving a GNU Units expression (accepted with a validation warning).

    Note: Give it when the type of the value is float or int; omit it when it is string or bool.

    description

    An explanation of the meaning, source, or purpose of the inference parameter.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —
    number-generated

    The number of outputs of the machine learning model kept in the dataset.

    Required Repeatable Type Extent Kind Rec. unit
    no no int [] dimensionless —

    Minimum: 1.

    Clarifications: A number drawn before filtering is stated in filtering.

    filtering

    What was removed from or kept among the model's outputs.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Clarifications: E.g. validity checks, deduplication, novelty against the training data or a stability pre-screen, with the fraction removed by each. Checks on the generated set (the fraction valid, unique or novel) are given here, as they describe the output, not the model.

    Example: ML Method-Specific Metadata

    Dataset source: https://figshare.com/articles/dataset/WyFormer_generated_structures/29094701

    {
  "ml": {
    "settings": [
      {
        "computation-label": [
          "wyformer-generation"
        ],
        "ml-task": {
          "type": [
            "Structure generation"
          ],
          "description": "Generation of inorganic crystal structures using a method that explicitly accounts for crystal symmetry."
        },
        "ml-model": {
          "algorithm": "Wyckoff Transformer (WyFormer)",
          "target-variable": [
            "Discrete Wyckoff encodings consisting of a space group identifier and sequence of element, site-symmetry, and enumeration tokens, which can be deterministically expanded into full 3D crystal structures."
          ],
          "input-feature": [
            "Tokenized representations of the space group, chemical elements, site symmetry labels, and Wyckoff position indices derived from symmetry analysis of crystal structures."
          ],
          "model-architecture": "A permutation-invariant autoregressive Transformer that generates crystal structures in a discrete Wyckoff representation by modeling the joint distribution of space group and symmetry-constrained site tokens.",
          "training-data": [
            {
              "name": "MP-20",
              "contents": "Inorganic crystalline materials relaxed using density functional theory (DFT) to a local energy minimum. There are 89 elements and the materials have 1–20 atoms in the unit cells. MP-20 includes most experimentally known materials with no more than 20 atoms in unit cell. Each item is a structure; the structures differ in both structure and composition.",
              "source": "Materials Project, first published in https://doi.org/10.1063/1.4812323",
              "size": 45231
            }
          ]
        },
        "inference": {
          "number-generated": 10000,
          "filtering": "Only formally valid Wyckoff representations are kept."
        }
      }
    ]
  }
}
