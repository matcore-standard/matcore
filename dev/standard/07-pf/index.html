    2.6 PF

    * = required property

    physical-phenomena*

    Material process being modeled; description of the overarching processes and mechanisms being modeled/simulated.

    Repeatable: True

    Values (legacy text): String containing one of the following values: "Isothermal solidification" "Directional solidification" "Isothermal annealing" "Sintering" "Twinning" "Grain growth" "Spinodal decomposition" Other user-specified value if none of the above apply.

    problem-specification*

    The fundamental mathematical and physical framework governing the phase field simulation, including the governing equations, thermodynamic free energy models, and time-evolution state

    Repeatable: False

    Values (legacy text): Contains SubProperties as listed below.

    time-dependence*

    Description of the time-evolution state targeted by the simulation.

    Repeatable: False

    Values (legacy text): String containing one of the following values: "Property prediction" "Transient evolution" "Steady state" "Stationary" "Thermodynamic equilibrium" Other user-specified value if none of the above apply.

    governing-equation*

    The specific phase field equation used to evolve a field variable.

    Repeatable: True

    Values (legacy text): Contains SubSubProperties as defined in the table below.

    type*

    The mathematical classification of the phase field equation.

    Repeatable: False

    Values (legacy text): String containing one of the following values: "CH" – Cahn-Hilliard "AC" – Allen-Cahn "GP" – Grand Potential "FID" – Finite Interface Dissipation "PFC" – Phase Field Crystal "Fluid" "Multi" "Coupled" "Diffuse" Other user-specified value if none of the above apply.

    evolved-variable*

    The name of the field-variable that this equation solves for.

    Repeatable: False

    Values (legacy text): A string matching a defined field-variable name (e.g., "phi", "c").

    driving-energy

    A free energy component that acts as a forcing term in this equation.

    Repeatable: True

    Values (legacy text): A string matching one of the defined free-energy names (e.g. "f_chem", "f_elastic").

    free-energy*

    The thermodynamic free energy function used in the system

    Repeatable: False

    Values (legacy text): Contains SubSubProperties as defined in the table below.

    name*

    The identifier or symbol used for this specific energy functional.

    Repeatable: False

    Values (legacy text): A string (e.g., "f_chem", "Chemical Free Energy").

    description*

    The type/derivation of the thermodynamic bulk free energy function.

    Repeatable: False

    Values (legacy text): String containing one of the following values: "Ideal" "Regular" "Flory" "Calphad" "Poly" "Non-polynomial" Other user-specified value if none of the above apply.

    expression

    The exact mathematical formulation of the phase field functional.

    Repeatable: False

    Values (legacy text): A string containing a code snippet, LaTeX formula, or SymPy expression.

    unit

    The physical unit of the free energy density.

    Repeatable: False

    Values (legacy text): A string in the GNU unit convention (or the text "dimensionless").

    additional-energy-contribution

    Physical contributions to the free energy function.

    Repeatable: True

    Values (legacy text): String containing one of the following values: "Elasticity" "Plasticity" "Electrical" "Magnetic" "Fluid-Solid-Interaction" "Solid-Solid-Interaction" Other user-specified value if none of the above apply.

    domain-and-mesh

    The spatial configuration, computational region, and topological discretization details.

    Repeatable: False

    Values (legacy text): Contains SubProperties as listed below.

    dimensionality*

    The spatial dimensions of the computational domain.

    Repeatable: False

    Values (legacy text): String containing one of the following values: "1D" "2D" "3D" Other user-specified value if none of the above apply.

    coordinate-system

    The structured framework used to uniquely determine and standardize the position of the points in space and the symmetry assumed.

    Repeatable: False

    Values (legacy text): String containing one of the following values: "Cartesian" "Cylindrical" "Spherical" Other user-specified value if none of the above apply.

    mesh-type

    The topology or distribution of the discrete grid points.

    Repeatable: False

    Values (legacy text): String containing one of the following values: "Regular" "Cartesian" "Rectilinear" "Skewed" "Curvilinear" "Unstructured" "Adaptive Mesh Refinement" "Meshless" Other user-specified value if none of the above apply.

    domain-size

    Specification of the computational region extents.

    Repeatable: False

    Values (legacy text): An ordered list of real numbers containing the domain dimensions in meters (m).

    boundary-conditions

    Constraints applied to the computational domain perimeter.

    Repeatable: True

    Values (legacy text): String containing one of the following values: "NoFlux" "Periodic" "Fixed" "Free" "Dirichlet" "Neumann" Other user-specified value if none of the above apply.

    initial-conditions

    The spatial distribution of the field variables at the start of the simulation.

    Repeatable: True

    Values (legacy text): A string describing the initialization method (e.g., "Uniform constant", "Random noise", "Geometric seed", "Imported array", a specific mathematical function, or other user-specified method)

    numerical-method*

    A description of the computational framework used to solve the phase field equations.

    Repeatable: True

    Values (legacy text): Contains SubProperties as listed below.

    spatial-discretization*

    The numerical approach used to convert continuous governing equations into a system of algebraic equations defined over a discrete mesh or set of points within the computational domain.

    Repeatable: False

    Values (legacy text): String containing one of the following values: "FDM" – Finite Difference Method "FEM" – Finite Element Method "FVM" – Finite Volume Method "LBM" – Lattice Boltzmann Method "Particle" "Spectral" Other user-specified value if none of the above apply.

    spatial-accuracy-order

    The exponent of the grid spacing parameter (Δx) determining the rate at which the discretization error approaches zero as the mesh is refined.

    Repeatable: False

    Values (legacy text): An integer containing the order of accuracy.

    Standard units (legacy text): dimensionless

    temporal-discretization

    The algorithm, step-size approach, and integration order used to advance a simulation, governing equation in time.

    Repeatable: False

    Values (legacy text): String containing one of the following values: "Forward Euler" "Backward Euler" "Adams Bashforth" "Implicit" "Explicit" "Crank-Nicholson" "Runge-Kutta" "Mixed" Other user-specified value if none of the above apply.

    temporal-accuracy-order

    The exponent of the time step parameter (Δt) determining the rate at which the discretization error approaches zero as the time step tends to zero.

    Repeatable: False

    Values (legacy text): An integer containing the order of accuracy.

    Standard units (legacy text): dimensionless

    grid-spacing

    Defines the physical distance between adjacent discretization points in a numerical domain.

    Repeatable: True

    Values (legacy text): Contains SubSubProperties as defined in the table below.

    name*

    The designation of the grid spacing parameter.

    Repeatable: False

    Values (legacy text): A string containing the name of the spacing metric, (e.g., "dx", "dy", "dz", "min", "max", "average").

    value*

    The data associated with the grid spacing parameter.

    Repeatable: False

    Values (legacy text): A real number containing the grid spacing value.

    unit*

    A standardized string or identifier that defines the dimension or measurement system of the associated value.

    Repeatable: False

    Values (legacy text): A string containing the units of the value in the GNU unit convention (or the text "dimensionless").

    description

    An explanation providing further clarification on the grid spacing parameter.

    Repeatable: False

    Values (legacy text): A string explaining the grid spacing parameter.

    time-step-size

    The discrete duration of progression between consecutive stages of a simulation, determining the interval for numerical integration, resolution of transient phenomena, and stability of the governing equations.

    Repeatable: True

    Values (legacy text): Contains SubSubProperties as defined in the table below.

    name*

    The designation of the time step size parameter.

    Repeatable: False

    Values (legacy text): A string containing the name of the time step metric, (e.g., "dt", "initial", "min", "max").

    value*

    The data associated with the time step size parameter.

    Repeatable: False

    Values (legacy text): A real number containing the magnitude of the time step.

    unit*

    A standardized string or identifier that defines the dimension or measurement system of the associated value.

    Repeatable: False

    Values (legacy text): A string containing the units of the value in the GNU unit convention (or the text "dimensionless").

    description

    An explanation providing further clarification on the time step size parameter.

    Repeatable: False

    Values (legacy text): A string explaining the time step size parameter.

    solver

    Specific numerical algorithm or backend used for solving the equations.

    Repeatable: True

    Values (legacy text): A string containing the solver name (e.g., "Newton-Krylov", "GMRES").

    variables

    Explicit data structure capturing changing and unchanging elements of the physics model.

    Repeatable: False

    Values (legacy text): Contains SubProperties as listed below.

    model-parameter

    A specific, adjustable, or calibrated numeric value that controls certain aspects of the simulation.

    Repeatable: True

    Values (legacy text): Contains SubSubProperties as defined in the table below.

    name*

    The designation of the model parameter.

    Repeatable: False

    Values (legacy text): A string containing the name of the model parameter (e.g. "kappa", "W", "mobility").

    value*

    The data associated with the model parameter.

    Repeatable: False

    Values (legacy text): An integer, real, boolean, or string containing the parameter value.

    unit*

    A standardized string or identifier that defines the dimension or measurement system of the associated value.

    Repeatable: False

    Values (legacy text): A string containing the units of the value in the GNU unit convention (or the text "dimensionless").

    description

    An explanation providing further clarification on the model parameter.

    Repeatable: False

    Values (legacy text): A string explaining the model parameter (e.g. "Gradient energy coefficient").

    field-variable

    A physical quantity that can evolve during the simulation.

    Repeatable: True

    Values (legacy text): Contains SubSubProperties as defined in the table below.

    name*

    The designation of the field variable.

    Repeatable: False

    Values (legacy text): A string containing the name of the field variable (e.g. "phi", "c", "T").

    type*

    The kind of data associated with the field variable.

    Repeatable: False

    Values (legacy text): A string containing: "Scalar" "Vector" "Tensor" Other user-specified value if none of the above apply.

    unit*

    A standardized string or identifier that defines the dimension or measurement system of the associated value.

    Repeatable: False

    Values (legacy text): A string containing the units of the value in the GNU unit convention (or the text "dimensionless").

    description

    An explanation providing further clarification on the field variable.

    Repeatable: False

    Values (legacy text): A string explaining what the field variable represents (e.g. "phase field order parameter", "solute concentration").
