    2.1 Minimal MatCore Metadata

    Version 0.5.0

    The minimal MatCore metadata includes aspects of a dataset deemed important to report for data findability and reuse and are universal across all computational methods. The list of minimal metadata is tabulated below.

    * required appears at most once repeatable

    creator*

    A primary entity (e.g. person, organization, software agent) responsible for creating the dataset's core content and their institutional affiliation if relevant.

    Required Repeatable
    yes yes
    name*

    The name of the entity that generated the dataset.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Examples: Albert Einstein, Lawrence Livermore National Laboratory, Claude Opus 5.5.

    identifier

    A unique, persistent identifier that globally and unambiguously identifies the entity that created the dataset.

    Required Repeatable
    no yes
    value*

    The identifier, in the form Annex I gives for its scheme when the scheme is listed there.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    scheme*

    The identifier scheme that the value belongs to.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: ORCID, ROR, DOI, SWHID, ISNI. Other values are allowed. For individuals, an ORCID ID; for organizations, an ROR ID; for software or AI agents, a Digital Object Identifier (DOI) generated specifically for the software code or version (e.g., a Zenodo software DOI) or a Software Heritage ID (SWHID) pointing to the exact software release or state. An ISNI may identify either individuals or organizations.

    structure*

    A system modeled in the dataset, e.g. a bulk crystal or a thin film on a substrate, and the materials that make it up.

    yes yes
    description

    material-component*

    One part of the structure, made of a single material, with its composition, form, role and phase.

    Required Repeatable
    yes yes
    formula*

    The chemical formula of the material component.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Pattern: [A-Za-z0-9.(){}+-]+. Examples: Si, SiO2, H2O2, Si0.7Ge0.3, Si{x}Ge{1-x}, (H2O)0.9(C2H6O)0.1, Ja0.8Jb0.2. A formula is a sequence of terms. A term is an element symbol, a user-defined species or a group in parentheses, each followed by an optional count. An element symbol is one of the 118 symbols of the IUPAC Periodic Table of the Elements (listed with atomic numbers 1 to 118 in the Standard Atomic Weights table of the IUPAC Commission on Isotopic Abundances and Atomic Weights). A user-defined species, for particles that are not chemical elements (e.g. in a Lennard-Jones model), is J followed by lowercase letters (e.g. Ja, Jlj); no element symbol begins with J. A count is a positive number, whole or decimal (e.g. H2O, Si0.7Ge0.3), or an expression in braces (e.g. Si{x}Ge{1-x}). A count of 1 is omitted. An expression contains at least one variable, given in variable, and is linear in its variables; it is built from numbers, one-letter variables, +, -, implied multiplication and parentheses (e.g. 1-x, 3x, 2(1-x)). A variable is used only when the composition varies, so a fixed composition is written with its numbers (e.g. Si0.3Ge0.7). A formula that is a sequence of two or more groups is a mixture of substances: the groups' counts are their mole fractions and sum to 1 (e.g. (H2O)0.9(C2H6O)0.1). Elements may appear in any order. A molecule is written with its molecular formula (e.g. H2O2, not HO). Separate phases, e.g. a film on a substrate, are separate material components.

    Required Repeatable

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Examples: InChI=1S/C2H6O/c1-2-3/h3H,2H2,1H3, CCO, ABC3_oP20_62_c_c_cd.

    scheme*

    The identifier scheme that the value belongs to.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: AFLOW, InChI, SMILES. Other values are allowed. For a molecule, InChI is preferred where it can represent it; SMILES otherwise or in addition. For a crystal, the AFLOW prototype label.

    form*

    The geometric form of the component as modeled.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: 2D material, Bulk, Chain, Cluster, Molecule, Monolayer, Nanoparticle, Nanoribbon, Nanotube, Nanowire, Slab, Thin film. Other values are allowed. One of: "2D material" – A crystalline solid that is a single unit cell thick (typically a few nanometers or less), while extending infinitely or to large dimensions in the lateral plane, e.g. graphene. "Bulk" – A material extending without bound in all three directions, e.g. a periodic crystal or a liquid. "Chain" – A one-dimensional sequence of atoms or monomers, e.g. an isolated polymer chain or a monatomic chain. "Cluster" – A finite aggregate of atoms or molecules, smaller than a nanoparticle. "Molecule" – A single molecule. "Monolayer" – A single layer of atoms or molecules deposited on another material. "Nanoparticle" – A solid particle of nanometer size in all three directions. "Nanoribbon" – A strip of a 2D material of nanometer width. "Nanotube" – A hollow cylinder of nanometer diameter, e.g. a carbon nanotube. "Nanowire" – A solid wire of nanometer diameter, extending without bound along its axis. "Slab" – A truncated bulk structure that can be used, for example, to model surfaces. "Thin film" – A layer of finite thickness, free-standing or on a substrate. The form is that of the component as modeled, e.g. a substrate modeled as a slab is a Slab.

    role

    The part the component plays in the structure.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Adsorbate, Core, Film, Inclusion, Layer, Matrix, Shell, Solute, Solvent, Substrate. Other values are allowed. One of: "Adsorbate" – A molecule, cluster or particle on the surface of a substrate. "Core" – The inner part of a particle, enclosed by a shell. "Film" – A layer of finite thickness on a substrate. "Inclusion" – A material enclosed in a matrix, e.g. a precipitate or an embedded nanotube. "Layer" – One of the layers of a layered structure, e.g. a heterostructure, a superlattice or a stack of 2D materials. "Matrix" – A material that encloses one or more inclusions. "Shell" – A layer enclosing a core. "Solute" – A material dissolved in a solvent. "Solvent" – A liquid in which a solute is dissolved. "Substrate" – A material on which a film, layer or adsorbate lies. Give a role for each component when the structure has more than one.

    fraction

    The atomic fraction of the structure made up of this component, i.e. the number of atoms in the component divided by the number of atoms in the structure.

    Required Repeatable
    no yes
    value*

    The value of the property.

    Required Repeatable Type Extent Kind Rec. unit
    yes no float [] dimensionless —

    From 0 to 1. The fractions of a structure's components sum to 1, for the entries without a qualifier and for each of Initial, Final and Average.

    qualifier

    What the value represents.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Average, Final, Initial, Maximum, Minimum. Other values are allowed. Without a qualifier, the value holds throughout the simulation and across the system, and the entry is the only one for the condition. Otherwise give one entry for each qualifier that applies, e.g. Initial and Final for a ramp, Minimum and Maximum for a range. For a vector or tensor, Minimum and Maximum are taken component by component.

    phase

    A phase of the material.

    Required Repeatable Type Extent Kind Rec. unit
    no yes string [] inapplicable —

    Recommended: Amorphous, Single crystal, Polycrystal, Quasicrystal, Liquid, Gas, Plasma. Other values are allowed. One of: "Amorphous" – A solid material without crystalline order. "Single crystal" – A solid material characterized by a repeating pattern of atoms that extends throughout it without interruption. "Polycrystal" – A solid material made of more than one crystalline grain of differing orientation. "Quasicrystal" – A solid material with long-range order but without translational periodicity, e.g. one whose diffraction pattern shows five-fold rotational symmetry. "Liquid" – A fluid structure (e.g. the molten state of a material). "Gas" – A state where molecules or atoms are far apart and only interact during collisions. "Plasma" – A gas comprised of ions and electrons. Omit for a component whose form is Molecule.

    Required Repeatable Type Extent Kind Rec. unit

    method-class*

    The general category to which the computational technique belongs.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: Electronic, Atomistic, Mesoscopic, Continuum, Data-driven. Other values are allowed.

    Note: The categories listed above are based on the MODA standard.

    method*

    The computational materials science (CMS) approach used in the computation.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Depends on method-class. For Electronic: Recommended: CC, QMC, DFT, MBPT. Other values are allowed. For Atomistic: Recommended: MC, MD. Other values are allowed. For Mesoscopic: Recommended: DDD, KMC, CGMD. Other values are allowed. For Continuum: Recommended: PF. Other values are allowed. For Data-driven: Recommended: ML. Other values are allowed. "CC" – Coupled Cluster; "QMC" – Quantum Monte Carlo; "DFT" – Density Functional Theory; "MBPT" – Many-Body Perturbation Theory methods (such as GW and BSE); "MC" – Monte Carlo; "MD" – Molecular Dynamics; "DDD" – Discrete Dislocation Dynamics; "KMC" – Kinetic Monte Carlo; "CGMD" – Coarse-grained MD; "PF" – Phase Field; "ML" – Machine Learning.

    Note: Give the method that produces the configurations or properties of the dataset. When another method supplies its energies and forces, give that one in interaction-model.

    interaction-model

    The model that supplies the energies and forces used by method, when it is a different method.

    Required Repeatable Type Extent Kind Rec. unit
    no yes string [] inapplicable —

    Recommended: CC, DFT, Empirical potential, ML potential, QMC, Tight binding. Other values are allowed. "CC" – Coupled Cluster; "DFT" – Density Functional Theory; "Empirical potential" – An interatomic potential with a fixed functional form fitted to data, e.g. Lennard-Jones or EAM; "ML potential" – A machine-learned interatomic potential, e.g. GAP or MACE; "QMC" – Quantum Monte Carlo; "Tight binding" – A semi-empirical electronic-structure model, e.g. DFTB. Give one entry per model, e.g. DFT and Empirical potential for a QM/MM simulation.

    simulation-conditions*

    The conditions imposed on the simulated system during the computation, e.g. by a thermostat, a barostat, a loading device or a fixed simulation cell.

    Required Repeatable
    yes no

    Note: The conditions below, other than type and description, are given as appropriate to the simulation. Each is imposed on the simulation as an external constraint. A quantity computed from the simulation, e.g. a heat flux measured under an imposed temperature gradient or the temperature of a microcanonical run, is a result, not a condition, and is not given here. A condition that varies is given as several entries, each with a qualifier; the description explains how it varies.

    type*

    The nature of the simulation being performed.

    Required Repeatable
    yes no

    Note: Detailed explanations of the simulation conditions are given in description.

    thermodynamic-state*

    Whether the simulated system is at equilibrium, in a steady state, or evolving in time.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: Equilibrium, Steady state, Transient. Other values are allowed. One of: "Equilibrium" – The system samples thermodynamic equilibrium. "Steady state" – A nonequilibrium state whose averages do not change in time, maintained by a driving such as a strain rate or a heat flux. "Transient" – A state whose averages change in time, e.g. relaxation toward equilibrium or a steady state, or a quench.

    system-openness

    What the system exchanges with its surroundings.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Isolated, Closed, Open. Other values are allowed. One of: "Isolated" – Exchanges neither energy nor particles, e.g. the microcanonical ensemble. "Closed" – Exchanges energy but not particles, e.g. the canonical or isothermal-isobaric ensemble. "Open" – Exchanges particles, or their species, with a reservoir, e.g. the grand-canonical or semi-grand-canonical ensemble.

    time-dependence

    How the imposed conditions change during the simulation.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Constant, Varying, Cyclic. Other values are allowed. One of: "Constant" – No imposed condition changes. "Varying" – An imposed condition changes, e.g. a temperature ramp or a change of ensemble. "Cyclic" – An imposed condition changes periodically, e.g. cyclic loading.

    spatial-uniformity

    How the imposed conditions vary across the system.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Uniform, Nonuniform, Periodic. Other values are allowed. One of: "Uniform" – Every imposed condition is the same throughout the system. "Nonuniform" – An imposed condition differs between parts of the system, e.g. a thermostat applied to part of it. "Periodic" – An imposed condition varies periodically across the system, e.g. sinusoidal heating. Not to be confused with cell-periodicity.

    description

    Explanatory text clarifying the simulation type, and how any condition varies in space or time, e.g. a temperature ramp, a thermostat applied to part of the system, or a composition set by chemical potentials. For a condition that varies, it states how, e.g. the shape of a ramp or the region a value applies to.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    cell

    The simulation cell, as imposed by the simulation.

    Required Repeatable
    no yes
    value*

    The value of the property, in the unit given by unit.

    Required Repeatable Type Extent Kind Rec. unit
    yes no float [3,3] Length angstrom

    Ordered list of three vectors (a, b, c), each with three components, that define the simulation cell. value[i][j] is the j-th Cartesian component, in the frame of the simulation, of the i-th cell vector, so the rows are a, b and c. The vectors (a, b, c) need not be orthogonal, and the magnitudes (|a|, |b|, |c|) are the cell vector lengths. The unit applies to all nine components.

    stress

    The stress, normal and shear components, imposed on the simulated system, e.g. by a barostat or an external loading device.

    Required Repeatable
    no yes

    Note 1: Requires cell, which defines the basis of the tensor components.

    Note 2: The adopted sign convention is for tensile normal stresses to be positive, and compressive normal stresses to be negative. This implies that for a material subjected to a positive pressure p, the stress tensor components are [-p, -p, -p, 0, 0, 0].

    value*

    The value of the property, in the unit given by unit.

    Required Repeatable Type Extent Kind Rec. unit
    yes no float [6] Pressure GPa

    The components of the (symmetric) Cauchy stress tensor σ in the following order: [σ11, σ22, σ33, σ23, σ13, σ12]. The stress components are expressed relative to an orthonormal basis (e1, e2, e3), where e1 is in the direction of a, e2 is in the direction of c╳a, and e3 = e1╳e2, where (a, b, c) are the vectors defining the cell, which may not be orthogonal. The unit applies to all six components.
