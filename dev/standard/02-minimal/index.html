    2.1 Minimal MatCore Metadata

    Version 0.4.0

    The minimal MatCore metadata includes aspects of a dataset deemed important to report for data findability and reuse and are universal across all computational methods. The list of minimal metadata is tabulated below.

    * required appears at most once repeatable

    creator*

    A primary entity (e.g. person, organization, software agent) responsible for creating the dataset's core content and their institutional affiliation if relevant.

    Required Repeatable
    yes yes
    name*

    The name of the entity that generated the dataset.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Examples: Albert Einstein, Lawrence Livermore National Laboratory, Claude Opus 5.5.

    identifier

    A unique, persistent identifier that globally and unambiguously identifies the entity that created the dataset.

    Required Repeatable
    no yes
    value*

    The identifier, in the form Annex I gives for its scheme when the scheme is listed there.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    scheme*

    The identifier scheme that the value belongs to.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: ORCID, ROR, DOI, SWHID, ISNI. Other values are allowed. For individuals, an ORCID ID; for organizations, an ROR ID; for software or AI agents, a Digital Object Identifier (DOI) generated specifically for the software code or version (e.g., a Zenodo software DOI) or a Software Heritage ID (SWHID) pointing to the exact software release or state. An ISNI may identify either individuals or organizations.

    phases*

    The phase(s) of the material included in the dataset.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [:] inapplicable —

    Recommended: Amorphous, Crystal, Quasicrystal, Molecule, Liquid, Gas, Plasma. Other values are allowed. One or more of: "Amorphous" – A solid material without crystalline order. "Crystal" – A solid material characterized by a repeating pattern of atoms. "Quasicrystal" – A crystal-like material with short-range order, but without long-range order. "Molecule" – A finite group of atoms bonded together forming an independent unit. "Liquid" – A fluid structure (e.g. the molten state of a material). "Gas" – A structure where atoms are far apart and only interact during collisions. "Plasma" – A gas comprised of ions and electrons.

    method-class*

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: Electronic, Atomistic, Mesoscopic, Continuum, Data-driven. Other values are allowed.

    Note: The categories listed above are based on the MODA standard.

    method*

    The computational materials science (CMS) approach used in the computation.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Depends on method-class. For Electronic: Recommended: CC, QMC, DFT, MBPT. Other values are allowed. For Atomistic: Recommended: MC, MD. Other values are allowed. For Mesoscopic: Recommended: DDD, KMC, CGMD. Other values are allowed. For Continuum: Recommended: PF. Other values are allowed. For Data-driven: Recommended: ML. Other values are allowed. "CC" – Coupled Cluster; "QMC" – Quantum Monte Carlo; "DFT" – Density Functional Theory; "MBPT" – Many-Body Perturbation Theory methods (such as GW and BSE); "MC" – Monte Carlo; "MD" – Molecular Dynamics; "DDD" – Discrete Dislocation Dynamics; "KMC" – Kinetic Monte Carlo; "CGMD" – Coarse-grained MD; "PF" – Phase Field; "ML" – Machine Learning.

    simulation-conditions*

    Required Repeatable
    yes no

    Note: The SubSubProperties listed below (aside from type and description) are provided as appropriate given the nature of the simulation. Providing a SubSubProperty means that its value is imposed on the simulation as an external constraint.

    Recommended: Equilibrium, Nonequilibrium, Other. Other values are allowed. "Equilibrium" – Thermodynamic equilibrium. "Nonequilibrium" – Conforming to some definition of nonequilibrium thermodynamics. "Other" – A simulation not fitting into the equilibrium and nonequilibrium categories.

    stress

    A uniform force per unit current area, including both normal and shear components, applied to the material during the simulation through contact with an external loading device.

    Required Repeatable
    no no

    Note 1: Requires the definition of the cell subproperty in order for a basis to be defined relative to which the tensor components are given.

    Note 2: The adopted sign convention is for tensile normal stresses to be positive, and compressive normal stresses to be negative. This implies that for a material subjected to a positive pressure p, the stress tensor components are [-p, -p, -p, 0, 0, 0].

    value*

    The value of the property, in the unit given by unit.

    Required Repeatable Type Extent Kind Rec. unit
    yes no float [6] Pressure GPa

    The components of the (symmetric) Cauchy stress tensor σ in the following order: [σ11, σ22, σ33, σ23, σ13, σ12]. The stress components are expressed relative to an orthonormal basis (e1, e2, e3), where e1 is in the direction of a, e2 is in the direction of c╳a, and e3 = e1╳e2, where (a, b, c) are the vectors defining the cell, which may not be orthogonal. The unit applies to all six components.
