    2.2 Density Functional Theory (DFT) Metadata

    Version 0.6.0

    The metadata for density functional theory (DFT) data (MatCore-DFT) is tabulated below. This includes the level of theory (exchange-correlation functional, core-electron model, and valence-electron model) and associated parameters. (Note: This standard inherits the metadata in the minimal MatCore standard, adding the properties below.)

    * required appears at most once repeatable

    settings*

    Settings shared by the computations named in it.

    Required Repeatable
    yes yes
    computation*

    The label of a computation these settings apply to.

    Required Repeatable Type Extent Kind Rec. unit
    yes yes string [] inapplicable —
    xc-functional*

    Approximation used to describe the electron exchange and electron correlation energies

    Required Repeatable
    yes yes
    type*

    The mathematical form of the exchange-correlation functional.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: LDA, GGA, Meta GGA, Hybrid, ML. Other values are allowed. "LDA" – Local Density Approximation. "GGA" – Generalized Gradient Approximation. "Meta GGA" – Extension to GGA including dependence on Laplacian of electron density. "Hybrid" – An approximation for the exchange-correlation (XC) functional that includes a portion of the exact XC from Hartree–Fock theory or machine learning with the rest coming from other sources (ab initio or empirical). "ML" – Machine learning based functional.

    name

    The exchange-correlation functional as the author names it.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Examples of possible content by type: LDA: Common parameterizations: VWN, PW92, etc. GGA: Typical choices are PW91, PBE, rPBE, revPBE, BLYP, etc. Meta GGA: Specific named examples include TPSS, SCAN, M06, etc. Hybrid: B3LYP, PBE0, HSE03, HSE06, NeuralXC, DeePKS, … ML: DM21, NNLDA, NNGGA, CIDER, etc. Others: BEEF, VdW-corrections (added on top of XC, e.g., D2, D3, D4), etc. A decomposition into the components of a community library such as LibXC is given in normalization.

    description

    Explanatory text providing more information about the type of the exchange-correlation method used including any relevant identifying information.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Free text on what type and name do not say, e.g. a modification of the functional or the reason for choosing it.

    normalization

    The functional decomposed into the components of a community library, which names the components.

    Required Repeatable
    no no
    components*

    The components of the functional, in the identifiers of the source.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [:] inapplicable —

    Examples: [GGA_X_PBE, GGA_C_PBE].

    source*

    The library whose identifiers the components use.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: LibXC. Other values are allowed. "LibXC" – the Libxc library of exchange-correlation functionals.

    xc-parameter

    A fixed variable associated with the specified exchange-correlation functional method.

    Required Repeatable
    no yes

    Note: For example, the mixing parameter of a hybrid exchange-correlation functional, or another method-specific parameter.

    name*

    The designation of the exchange-correlation parameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    value*

    The data associated with the exchange-correlation parameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no any any any —
    unit*

    The unit in which the associated value is expressed.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    A symbol from the MatCore Unit Table (Annex U), or the reserved symbol dimensionless. If and only if no Annex U symbol applies, a string prefixed x-gnu: giving a GNU Units expression (accepted with a validation warning).

    description

    An explanation of the meaning, source, or purpose of the parameter.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —
    core-electron-treatment*

    The treatment of the core electrons in the calculation.

    Required Repeatable
    yes no
    type*

    The method used to treat the core electrons.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: All-electron, PAW, Pseudopotential. Other values are allowed. "All-electron" – All of the electrons in an atom are modeled explicitly. "PAW" – Projector Augmented Wave. "Pseudopotential" – Valence electrons are treated explicitly, and core electrons are modeled by a simplified potential.

    Required Repeatable Type Extent Kind Rec. unit

    file

    The pseudopotential or PAW dataset file, with its checksums.

    Required Repeatable
    no no

    Note: Use file when the pseudopotential or PAW dataset is identified by a checksum of its file (e.g. the SHA256 hash of a VASP POTCAR file). For any other designation, use unique-identifier.

    name*

    The name of the file.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    checksum*

    A digital fingerprint of the file, computed by a named algorithm.

    Required Repeatable
    yes yes
    algorithm*

    The algorithm that computed the checksum.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: SHA1, SHA224, SHA256, SHA384, SHA512, SHA3-256, SHA3-384, SHA3-512, BLAKE2b-256, BLAKE2b-384, BLAKE2b-512, BLAKE3, MD2, MD4, MD5, MD6, ADLER32. Other values are allowed. The algorithm names of SPDX 2.3.1 §8.4 (File checksum field).

    value*

    The checksum of the file, in lowercase hexadecimal digits.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Pattern: [0-9a-f]+.

    unique-identifier

    A token other than a checksum that identifies the pseudopotential or PAW dataset, such as a label or code assigned by the library that distributes it.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Note: For a checksum of the pseudopotential or PAW dataset file, use file instead.

    wavefunction-representation*

    The representation used to expand the electronic wave functions.

    Required Repeatable
    yes no
    type*

    The method used to represent the electronic wave functions.

    Required Repeatable Type Extent Kind Rec. unit
    yes yes string [] inapplicable —

    Recommended: Gaussian basis sets, LAPW, Local atomic orbitals, Numerical atomic orbitals, Plane waves, Real space grids. Other values are allowed. The terms fall into three groups. (1) Basis-function expansions: "Gaussian basis sets" – Atom-centered Gaussian-type orbitals. "Local atomic orbitals" – Atom-centered orbitals of a form not covered by the previous or the next term, e.g. Slater-type orbitals. "Numerical atomic orbitals" – Atom-centered orbitals tabulated numerically, zero beyond a cutoff radius. "Plane waves" – Periodic plane waves up to a kinetic-energy cutoff. (2) Grid methods: "Real space grids" – Values on a mesh of points in real space (finite differences or finite elements). (3) Augmented methods: "LAPW" – Linearized Augmented Plane Wave: atomic-like functions inside spheres around the atoms, plane waves between them.

    kinetic-energy-cutoff

    For type "LAPW" or "Plane waves", the maximum kinetic energy of the plane waves included in the calculation of wave functions.

    Required Repeatable
    no no
    value*

    Required Repeatable Type Extent Kind Rec. unit
    yes no float [] Energy eV

    Minimum: 0.

    unit*

    The unit of the value, an Annex U symbol whose Kind is the Kind of value.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    charge-density-cutoff

    For type "LAPW" or "Plane waves", the energy value used to truncate the plane wave expansion of the electron charge density.

    Required Repeatable
    no no
    value*

    The value of the property, in the unit given by unit.

    Required Repeatable Type Extent Kind Rec. unit
    yes no float [] Energy eV

    Minimum: 0.

    unit*

    The unit of the value, an Annex U symbol whose Kind is the Kind of value.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    calculation-physics

    Additional phenomena included beyond the standard DFT calculation.

    Required Repeatable Type Extent Kind Rec. unit
    no yes string [] inapplicable —

    Recommended: Collinear spin polarization, Noncollinear spin polarization, On-site correlation, Orbital polarization, Spin-orbit coupling, Van der Waals. Other values are allowed. "Collinear spin polarization" – Spin-polarized, with all magnetic moments parallel or antiparallel to one axis. "Noncollinear spin polarization" – Spin-polarized, with magnetic moments free to point in any direction. "On-site correlation" – e.g. DFT+U. "Orbital polarization" – A correction that enhances the orbital magnetic moment, e.g. Brooks' orbital-polarization term. "Spin-orbit coupling" – The coupling of the electron spin to its orbital motion. "Van der Waals" – Dispersion interactions, by a correction or a nonlocal functional. Give at most one of the two spin-polarization terms. List each phenomenon as a separate entry, e.g. a noncollinear calculation with spin-orbit coupling has two entries, "Noncollinear spin polarization" and "Spin-orbit coupling".

    k-point-mesh

    For periodic systems, a grid of points sampled within the Brillouin zone, used to approximate integrals and calculate electronic properties by discretizing the wavefunction across reciprocal space.

    Required Repeatable
    no no
    type*

    The choice of how k-points are distributed on the mesh.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: Regular gamma-centered, Regular shifted, Irregular. Other values are allowed.

    number-of-points

    The number of k-points included along each reciprocal lattice vector.

    Required Repeatable Type Extent Kind Rec. unit
    no no int [3] dimensionless —

    Minimum: 1, for each component. Ordered list of three integers, the number of k-points along the three reciprocal lattice vector directions.

    shift

    Translation of the k-point mesh along the reciprocal lattice vector directions.

    Required Repeatable Type Extent Kind Rec. unit
    no no float [3] dimensionless —

    Ordered list of three real numbers, the shifts along the three reciprocal lattice vector directions. Shifts are given as fractions of the mesh spacing along each reciprocal lattice vector.

    smearing-type

    The choice of method for assigning fractional occupancies of electronic states and/or facilitating reciprocal space integrations.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: None, None - tetrahedron, None - Blöchl-corrected tetrahedron, Gaussian, Fermi-Dirac, Methfessel-Paxton, Marzari-Vanderbilt. Other values are allowed.

    description

    An explanation of the meaning, source, or purpose of the parameter.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —
    self-consistent-field-convergence

    Method and termination criteria defining the precision of self-consistent solution of the Kohn-Sham equations.

    Required Repeatable
    no no
    method-density

    The self-consistent field mixing and/or extrapolation scheme for the iterative solution of the Kohn-Sham equations.

    Required Repeatable Type Extent Kind Rec. unit
    no no string [] inapplicable —

    Recommended: Simple mixing, Pulay mixing, DIIS, Broyden mixing. Other values are allowed. "DIIS" – Direct Inversion in the Iterative Subspace.

    method-diagonalization

    The method used to obtain the Kohn-Sham orbitals at each step of the self-consistent loop.

    Required Repeatable Type Extent Kind Rec. unit
    no yes string [] inapplicable —

    Recommended: Car-Parrinello, Chebyshev filtering, Conjugate gradient, Davidson method, Direct diagonalization, Lanczos, LOBPCG, RMM-DIIS. Other values are allowed. "Car-Parrinello" – Fictitious dynamics of the electronic orbitals, which replaces diagonalization. "Chebyshev filtering" – Subspace iteration with Chebyshev polynomial filters. "Davidson method" – Including blocked variants. "Direct diagonalization" – A dense eigensolver applied to the full Hamiltonian matrix (e.g. LAPACK, ScaLAPACK). "LOBPCG" – Locally Optimal Block Preconditioned Conjugate Gradient. "RMM-DIIS" – Residual Minimization Method with Direct Inversion in the Iterative Subspace.

    tolerance*

    Convergence criterion for the self-consistent loop.

    Required Repeatable
    yes no
    criterion*

    The quantity whose convergence the tolerance measures.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    Recommended: Energy, Charge density, Potential. Other values are allowed. "Energy" – The change in the energy between successive iterations, defined as for relaxation-tolerance-energy. "Charge density" – The change or residual of the electron density. "Potential" – The change or residual of the Kohn-Sham potential.

    value*

    The value of the property, in the unit given by unit.

    Required Repeatable Type Extent Kind Rec. unit
    yes no float [] any —

    Minimum: 0.

    unit*

    The unit in which the associated value is expressed.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —

    A symbol from the MatCore Unit Table (Annex U), or the reserved symbol dimensionless. If and only if no Annex U symbol applies, a string prefixed x-gnu: giving a GNU Units expression (accepted with a validation warning).

    relaxation-tolerance-energy

    Energy convergence criterion for atomic relaxation.

    Required Repeatable
    no no

    Note: The energy is the Helmholtz free energy F = E − TS, including the entropy S of the smeared electrons at the smearing temperature T, when occupations are smeared (e.g. a metal), and the total energy E otherwise (e.g. an insulator). It is not the energy extrapolated to zero smearing.

    The value of the property, in the unit given by unit.

    Required Repeatable Type Extent Kind Rec. unit
    yes no float [] Energy eV

    Minimum: 0.

    unit*

    The unit of the value, an Annex U symbol whose Kind is the Kind of value.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    relaxation-tolerance-forces

    Required Repeatable
    no no
    value*

    The value of the property, in the unit given by unit.

    Required Repeatable Type Extent Kind Rec. unit
    yes no float [] Force eV/angstrom

    Minimum: 0.

    unit*

    The unit of the value, an Annex U symbol whose Kind is the Kind of value.

    Required Repeatable Type Extent Kind Rec. unit
    yes no string [] inapplicable —
    comment

    Additional information on the DFT calculation. For example, non-self-consistent constraints, such as details about imposed state occupation or moment freezing.

    Required Repeatable Type Extent Kind Rec. unit
    no yes string [] inapplicable —

    "settings": [
      {
        "computation": [
          "dft-single-points"
        ],
        "xc-functional": [
          {
            "type": "GGA",
            "name": "PW91",
            "description": "PW91 functional (the choice is motivated by the existence of a large-scale simulation of the melting point with this functional)"
          }
        ],
        "core-electron-treatment": {
          "type": "Pseudopotential",
          "pseudopotential-or-paw": [
            {
              "name": "Ultrasoft Pseudopotentials (USP)",

              "number-of-valence-electrons": 4
            }
          ]
        },
        "wavefunction-representation": {
          "type": [
            "Plane waves"
          ],
          "kinetic-energy-cutoff": {
            "value": 250.0,
            "unit": "eV"
          }
        },
        "k-point-mesh": {
          "type": "Regular shifted",
          "smearing-width": {
            "value": 0.05,
            "unit": "eV"
          }
        }
      }
    ]
  }
