    2.2 Density Functional Theory (DFT) Metadata

    Version 0.5.0

    The metadata for density functional theory (DFT) data (MatCore-DFT) is tabulated below. This includes the level of theory (exchange-correlation functional, core-electron model, and valence-electron model) and associated parameters. (Note: This standard inherits the metadata in the minimal MatCore standard, adding the properties below.)

    * required appears at most once repeatable

    xc-functional*

    Approximation used to describe the electron exchange and electron correlation energies

    Required Repeatable
    yes yes
    type*

    The mathematical form of the exchange-correlation functional.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: String containing one of the following values: "LDA" – Local Density Approximation "GGA" – Generalized Gradient Approximation "Meta GGA" – Extension to GGA including dependence on Laplacian of electron density "Hybrid" – An approximation for the exchange-correlation (XC) functional that includes a portion of the exact XC from Hartree–Fock theory or machine learning with the rest coming from other sources (ab initio or empirical). "ML" – Machine learning based functional Other user-specified value if none of the above apply.

    description

    Explanatory text providing more information about the type of the exchange-correlation method used including any relevant identifying information.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: A string containing more information about the exchange-correlation type. Examples of possible content by type: LDA: Common parameterizations: VMN, PW92, etc. GGA: Typical choices are PW91, PBE, rPBE, revPBE, BLYP, etc. Meta GGA: Specific named examples include TPSS, SCAN, M06, etc. Hybrid: B3LYP, PBE0, HSE03, HSE06, NeuralXC, DeePKS, … ML: DM21, NNLDA, NNGGA, CIDER, etc. others: BEEF, VdW-corrections (added on top of XC, e.g., D2, D3, D4), etc. LibXC designation: LibXC:LDA_C_GK72 (include source as prefix)

    xc-parameter

    A fixed variable associated with the specified exchange-correlation functional method.

    Required Repeatable
    no yes
    name*

    The designation of the exchange-correlation parameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: A string containing the name of an exchange-correlation parameter.

    value*

    The data associated with the exchange-correlation parameter.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: An integer, real, boolean, or string containing the parameter value.

    unit*

    A standardized string or identifier that defines the dimension or measurement system of the associated value.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: A string containing the units of the value in the GNU unit convention (or the text "dimensionless").

    description

    An explanation of the meaning, source, or purpose of the parameter.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: A string explaining the exchange-correlation parameter. This can be the mixing parameter for a hybrid exchange-correlation, or other method-specific parameters.

    core-electron-model*

    Model of the electrons used in the calculation.

    Required Repeatable
    yes no
    type*

    The method used to model the electrons.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: String containing one of the following values: "All Electron" – All of the electrons in an atom are modeled explicitly. "LAPW" – "Linearized Augmented Plane Wave" "Pseudopotential" – Valence electrons are treated explicitly, and core electrons are modeled by a simplified potential. "PAW" – Projector Augmented Wave Other user-specified value if none of the above apply.

    pseudopotential

    For type "Pseudopotential", or type "PAW", additional information about the pseudopotentials.

    Required Repeatable
    no yes
    name*

    The name of the pseudopotential.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: A string containing the pseudopotential name.

    type*

    The physical form of the pseudopotential.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: String containing one of the following values: "Norm conserving" "Ultrasoft" Other user-specified value if none of the above apply.

    description

    Explanatory text about the pseudopotential including any relevant identifying information.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: A string containing the pseudopotential description.

    number-of-valence-electrons*

    The number of electrons treated explicitly.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: An integer containing the number of valence electrons. Legacy unit: dimensionless

    repository

    The database from which the pseudopotential was obtained.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: String containing the name of the repository.

    version

    The version of the pseudopotential.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: A string containing the pseudopotential version (e.g. "6.3.1")

    doi

    The digital object identifier (DOI) for the pseudopotential.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: A string containing the pseudopotential DOI.

    unique-identifier

    A hash or other token providing a digital signature for the pseudopotential.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: A string containing the pseudopotential identifier (e.g. a SHA256 hash for a VASP pseudopotential).

    valence-electron-model*

    The elementary functions used for expanding electronic wave functions.

    Required Repeatable
    yes no
    type*

    The choice of a basis set to expand electronic wave functions.

    Required Repeatable Type Extent Kind Rec. unit
    yes yes — — — —

    Legacy: String containing one of the following values: "Plane waves" "LAPW" – "Linearized Augmented Plane Wave" "Localized orbitals" "PAW" Other user-specified value if none of the above apply.

    localized-orbital-basis-set

    For type "Localized orbitals", additional information about the localized orbital basis set.

    Required Repeatable
    no yes
    type*

    The designation of the set of orbital functions used for expanding electronic wave functions.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: String containing the basis set name (e.g. "6-31G", "DZP", etc.).

    repository

    The database from which the localized-orbital basis set was obtained.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: String containing the name of the repository.

    version

    The version of the localized-orbital basis set.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: A string containing the localized-orbital basis set version.

    doi

    The digital object identifier (DOI) for the localized-orbital basis set.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: A string containing the pseudopotential DOI.

    unique-identifier

    A hash or other token providing a digital signature for the localized-orbital basis set .

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: A string containing the localized-orbital basis set identifier.

    kinetic-energy-cutoff

    For type not "Localized orbitals", the maximum kinetic energy of the plane waves included in the calculation of wave functions.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: Real number containing the kinetic energy cutoff. Legacy unit: electron Volt (eV)

    charge-density-cutoff

    For type not "Localized orbitals", the energy value used to truncate the plane wave expansion of the electron charge density,

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: Real number containing the charge density cutoff. Legacy unit: electron Volt (eV)

    calculation-physics

    Additional phenomena included beyond the standard DFT calculation.

    Required Repeatable Type Extent Kind Rec. unit
    no yes — — — —

    Legacy: String containing one of the following values: "Relativistic effects" "Spin polarization" "Noncollinear spin polarization" "On-site correlation" (e.g. DFT+U) "Van der Waals" Other user-specified value if none of the above apply.

    k-point-mesh

    For periodic systems, a grid of points sampled within the Brillouin zone, used to approximate integrals and calculate electronic properties by discretizing the wavefunction across reciprocal space.

    Required Repeatable
    no no
    type*

    The choice of how k-points are distributed on the mesh.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: String containing one of the following values: "Monkhorst-Pack" "Gamma centered" "Irregular" Other user-specified value if none of the above apply.

    number-of-points

    How many k-points are included along each reciprocal lattice vector.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: Ordered list of three integer numbers containing the number k-points along the three reciprocal lattice vector directions. Legacy unit: dimensionless

    k-point-spacing

    Separation between k-points along each reciprocal lattice vector direction.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: Real number containing the k-point spacing. Legacy unit: 1/angstrom (1/Å)

    State whether the factor 2π is included in the reciprocal length.

    shift

    Translation of the k-point mesh along the reciprocal lattice vector directions.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: Ordered list of three real numbers containing the shifts along the three reciprocal lattice vector directions. Legacy unit: 1/angstrom (1/Å)

    smearing-type

    The choice of method for assigning fractional occupancies of electronic states and/or facilitating reciprocal space integrations.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: String containing one of the following values: "None" "None - tetrahedron" "None - Blöchl-corrected tetrahedron" "Gaussian" "Fermi" "Methfessel-Paxton" Other user-specified value if none of the above apply.

    smearing-width

    A parameter that controls the broadening of the electron energy levels near the Fermi level.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: Real number containing the smearing width. Legacy unit: electron Volt (eV)

    methfessel-paxton-order

    For smearing-type "Methfessel-Paxton", level of polynomial approximation used in the Methfessel-Paxton smearing method

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: Integer containing the Methfessel-Paxton order. Legacy unit: dimensionless

    self-consistent-field-convergence

    Method and termination criteria defining the precision of self-consistent solution of the Kohn-Sham equations.

    Required Repeatable
    no no
    method

    The self-consistent field mixing and/or extrapolation scheme for the iterative solution of the Kohn-Sham equations.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: String containing one of the following values: "Simple mixing" "Pulay mixing" "Blocked Davidson" "DIIS" – Direct Inversion in the Iterative Subspace "BFGS" – Broyden–Fletcher–Goldfarb–Shanno algorithm Other user-specified value if none of the above apply.

    tolerance*

    Convergence criterion (on total energy) for the self-consistent loop.

    Required Repeatable Type Extent Kind Rec. unit
    yes no — — — —

    Legacy: Real number containing the convergence tolerance Legacy unit: electron Volt (eV)

    relaxation-tolerance-energy

    Total energy convergence criterion for atomic relaxation.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: Real number containing the convergence tolerance Legacy unit: electron Volt (eV)

    relaxation-tolerance-forces

    Maximum force convergence criterion for atomic relaxation.

    Required Repeatable Type Extent Kind Rec. unit
    no no — — — —

    Legacy: Real number containing the convergence tolerance Legacy unit: electron Volt (eV/Å)

    comment

    Additional information on the DFT calculation. For example, non-self-consistent constraints, such as details about imposed state occupation or moment freezing.

    Required Repeatable Type Extent Kind Rec. unit
    no yes — — — —

    Legacy: String containing the calculation comments.

    Example: DFT Method-Specific Metadata

    Dataset source: https://doi.org/10.60732/8e9bc5b0

    <?xml version="1.0" encoding="UTF-8"?>
<root>
  <xc-functional>
    <type>GGA</type>
    <description>PW91 functional (the choice is motivated by the existence of a large-scale simulation of the melting point with this functional)</description>
  </xc-functional>
  <core-electron-model>
    <type>Pseudopotential</type>
    <pseudopotential>
      <name>Ultrasoft Pseudopotentials (USP)</name>
      <type>Ultrasoft</type>
      <number-of-valence-electrons>4</number-of-valence-electrons>
    </pseudopotential>
  </core-electron-model>
  <valence-electron-model>
    <type>Plane waves</type>
    <kinetic-energy-cutoff>250.0</kinetic-energy-cutoff>
  </valence-electron-model>
  <k-point-mesh>
    <type>Monkhorst-Pack</type>
    <k-point-spacing>0.03</k-point-spacing>
    <smearing-width>0.05</smearing-width>
  </k-point-mesh>
</root>
